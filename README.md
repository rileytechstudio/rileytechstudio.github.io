# rileytechstudio.github.io
this is the github page for riley childrens hospital's Child Life Department's static pages. they are mostly tools and educational games used by ccls in the hospital. all of these webpages are STATIC, meaning they do not store or transmit any data. they run completely locally on the client side without exposing any data to the internet. 
all projects here are published in the public domain, but you may attribute riley children's hospital find these tools helpful.
